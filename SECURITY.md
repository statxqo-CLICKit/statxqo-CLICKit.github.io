# Security Policy
Report vulnerabilities privately to statxqo@gmail.com (or via GitHub private vulnerability reporting). Please do not open public issues for security problems. We aim to reply within 72 hours.
Smart contracts: FOMO contracts on Base Sepolia are testnet and unaudited. Source is verified on Basescan.
RX7 VAPOR (/rx7-vapor/): read-only wallet scanner; it never holds keys or signs. Its admin unlock is a client-side convenience gate, not a security boundary.
