        Device Clean-Up

        Galaxy S25+ guide. Each button opens the right screen; you confirm every change there. If one doesn't open, use the path shown.
        1 · Group apps into foldersLong-press an app, drag it onto another to make a folder. Suggested folders: Crypto, Money, Social, Shopping, Media, Tools, Google, Samsung. Then Settings › Home screen › turn on "Lock home screen layout".
        Home screen settings
        2 · Remove unused appsSettings › Apps › sort by last used. Uninstall what you don't open.
        Unused appsAll apps
        3 · PhotosGallery › Albums › ⋮ › "Create album" by topic; Gallery › ⋮ › Settings › "Clean out" finds duplicates and blurry shots.
        Open Gallery
        4 · Files and storageMy Files › Analyze storage (large and duplicate files). Files by Google › Clean finds junk, duplicates, old downloads.
        My FilesFiles by GoogleStorage
        5 · Cap incoming dataTurn on Data Saver; set a mobile data limit; block background data per app (Apps › app › Mobile data).
        Data usageConnections
        6 · Cap notificationsSettings › Notifications › App notifications: switch off the noisy ones. Use Do not disturb for quiet hours.
        App notificationsDo not disturb
        7 · Security sweepWatchdog 4.0 (offline app scanner, C.L.I.C.K.it) is coming to Google Play. Until then: Settings › Security and privacy › App security.
        Security
        Coming in the native Android app: one-tap folder grouping by category, a photo and file organizer (by date and type, duplicates, large files, confirm before any delete), and a per-app data firewall. No root.
